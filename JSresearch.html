Overview: JavaScript is one of the world's most widely used programming languages, originally developed as an implementation of the ECMAScript standard, a specification maintained by the European Computer Manufacturers Association (ECMA) that defines how scripting languages should behave. ECMAScript provides the core rules and syntax that form the foundation of languages like JavaScript and Microsoft's JScript. Introduced in 1996, JScript was Microsoft's own version of ECMAScript, created to ensure compatibility with web browsers while avoiding trademark conflicts with JavaScript. Together, these technologies shaped the modern web, enabling dynamic, interactive experiences that go far beyond static HTML pages.

History and evolution of JavaScript

In September 1995, Brendan Eich, a programmer at Netscape developed a programming language in just 10 days. This language was initially called Mocha, then LiveScript. In December 1995 Netscape and Sun(the organisation that owned Java) had a license agreement regarding Javascript hence it was renamed to Javascript and specifically "Java" script because Java was the most popular language at that time and this would help the marketing of Javascript as well. Javascript grew rapidly since then and in 1997 ECMA was given the responsibility to create a specification for the language

JScript

When Netscape first introduced JavaScript, the web browser market was fiercely competitive. Each company wanted to create its own version of the language, often using different names and syntax. In 1996, shortly after Netscape released Navigator 3, Microsoft launched Internet Explorer 3, which included its own implementation of JavaScript known as JScript. Since JavaScript was open and freely licensed, Microsoft was able to reverse-engineer it to build its version. This led to two similar but incompatible versions of JavaScript, with no official standard to unify them. As a result, developers faced constant frustration, code that worked flawlessly in one browser would often fail completely in another.

ECMAScript

To avoid further conflicts, in 1997, Netscape turned to the European Computer Manufacturers Association (ECMA) and asked them to standardize JavaScript. By doing so, Netscape opened JavaScript to a broader community of developers and browser vendors, allowing everyone to contribute to its future while ensuring consistent governance. The ECMA committee created a standard known as ECMA-262, which defined a new scripting language called ECMAScript. This general-purpose scripting language was adopted by all browsers as the basis for their own implementations of JavaScript.
