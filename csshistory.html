CSS (Cascading Style Sheets) is a style sheet language to explain the appearance of a document created in HTML or XML, CSS specifies how elements should be delivered on screens, paper, in speech, or on other media, which are essential to web development and design.

A Brief History of CSS

CSS, or Cascading Style Sheets, first emerged in the early 1990s as a solution to the growing complexity of web design. The web was in its infancy, and designers were limited in their ability to control the appearance of web pages. Web content was mostly text-based, and HTML (HyperText Markup Language) was the primary tool for structuring web documents. In 1994, Hakon Wium Lie, a Norwegian web pioneer, and Bert Bos, a Dutch programmer, proposed the first CSS specification. Their vision was to separate content (HTML) from presentation (CSS), thus simplifying web development and making it more flexible. The difference between HTML and CSS lies in their roles: HTML structures web content, while CSS styles and formats that content.

CSS Version History

  • CSS1 (1996): The first official CSS specification, CSS1, was introduced in 1996. It allowed for basic stylings, such as changing text colors, fonts, margins, padding, and backgrounds.
  • CSS2 (1998): CSS2, released in 1998, introduced a plethora of new features, by adding more sophisticated selectors, positioning capabilities, media types, and additional properties to enhance styling options.
  • CSS2.1 (2011): This version focused on clarifying and improving the CSS2 specification. It became a W3C Recommendation in June 2011 and is widely supported across all major browsers.
  • CSS3 (ongoing): CSS3 is not a single monolithic release but a collection of modular specifications introduced gradually. These modules cover various aspects of web design, such as animations, gradients, and flexible box layouts.
  • CSS4 (in development): CSS4 is the future of CSS, aiming to further enhance web design capabilities, including responsive design, variable fonts, and improved grid systems.

What is CSS Ruleset?

A CSS ruleset is the foundation of how styles are used on an HTML element on a webpage. It's a combination of a selector and one or more declarations that describe how elements are displayed. The selector targets HTML elements to apply styles. Declarations are combinations of property names and values that specify how the chosen elements will be styled.

Selectors:

  • Universal Selector which targets all the elements that are visible on the screen that means it targets the complete cross-axis and main-axis of the screen.
  • Type Selector which targets specific HTML tags.
  • Class Selector which targets elements with a specific class attribute.
  • ID Selector which targets an element with a specific id attribute.
  • Grouping Selector which applies the same style to multiple elements.
  • Descendant Selector which helps to apply rule sets to all the children of a parent.
  • Child Selector which targets all direct children of a parent.

Declarations:

  • Color and Background
  • Font and Text
  • Box Model
  • Positioning
  • Flexbox
